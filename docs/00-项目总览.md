# 00 · 项目总览

> 读这一篇的目的：搞清楚「逐日」到底做什么、不做什么、用户怎么用它。
> 上层入口：`../AGENTS.md`

---

## 1. 产品定位

一句话：**给某一天安排几件事，勾掉它，然后看见自己坚持了多久。**

它介于三种东西之间：

- 比「番茄钟」轻 —— 不管计时，只管「今天这几件事」；
- 比「系统日历」温 —— 日历只负责提醒时间，逐日负责承载「我今天做到了没有」；
- 比「打卡 App」自由 —— 不逼你连续打卡，休息日不算断。

目标用户：想在手机上有一个**干净、安静、没有广告和会员弹窗**的地方，安排自己的每一天，并且想看到自己完成度趋势的人。

## 2. 与市面产品的差异（做这块时的取舍依据）

| 常见产品的问题 | 逐日的做法 |
|---|---|
| 打开先看广告 / 弹窗推会员 | 纯本地，无网络权限，冷启动直达今日清单 |
| 功能面板复杂（项目 / 标签 / 优先级 / 看板 / 番茄钟） | 只保留 5 个字段：标题、详情、日期、重复、时间 |
| 强迫「连续打卡」，断一天清零 | 连续天数只统计「有任务且全部完成」的日子，**没安排任务的日子不算断** |
| 统计页堆砌一堆指标 | 只给 4 个数字 + 2 张图：连续天数、今日完成度、30 天平均、累计完成件数、近 7 天柱状、近 8 周热力 |
| 界面花哨、信息密度低 | 暖纸色底 + 单一强调色 + 强字重对比，一屏看清今天 |

## 3. 功能边界

### 做（v1.0 全部已实现）
- 给任意日期（过去 / 今天 / 未来）安排任务
- 任务只有标题也能存；有详情时列表里也展示详情
- 重复：不重复 / 每天 / 每周指定星期几 / 每月指定号
- 可选时间（只作为展示标签，不做闹钟提醒）
- 勾选完成 / 取消完成
- 今日、日历、总结三个视图
- 暗色模式跟随系统

### 不做（刻意砍掉，别加回来）
- ❌ 云同步 / 账号 / 登录（会带来网络权限与隐私成本）
- ❌ 通知与闹钟（用户明确说「只要能设置、能看」）
- ❌ 提醒、优先级、标签、子任务、附件、协作
- ❌ 番茄计时、白噪音、成就体系
- ❌ 小组件、桌面图标角标（v2 再议）

## 4. 信息架构

```
逐日
├── 今日（默认 Tab）
│   ├── 日期头（年月 / 日 / 星期 / 当日完成度环）
│   ├── 日期条（横向滑动，可选任意一天）
│   ├── 任务清单（待办 → 已完成，两组）
│   └── 悬浮「添加」按钮 → 任务编辑器
├── 日历
│   ├── 月视图（有任务的日期下方打点，今天描边，选中实心）
│   └── 选中日期的任务清单（同组件复用，可勾选）
└── 总结
    ├── 连续天数（深色主卡）
    ├── 三个数字（今日 / 30 天平均 / 累计完成）
    ├── 近 7 天完成度柱状图
    └── 近 8 周完成度热力图
```

## 5. 核心用户旅程（验收时按这条走一遍）

1. 首次打开 → 今日清单为空，看到一句「今天还空着 / 加一件小事，让今天有迹可循」。
2. 点「添加」→ 底部抽屉弹出，输入「读 20 页书」，加一句详情，选今天，重复选「每天」→ 保存。
3. 回到清单，看到这条任务，点左侧圆圈勾掉 → 圆圈变实心、标题划掉、轻微下沉动画，顶部完成度环走到 100%。
4. 切到「日历」→ 今天有 1 个点；点明天的格子 → 空清单 + 添加按钮可用。
5. 给明天加一件事，重复设「每周 · 一三五」。
6. 切到「总结」→ 连续 1 天、今日 100%、近 7 天柱状图今天满格、热力图今天一格点亮。
7. 杀掉 App 重开 → 数据仍在。
8. 系统切暗色 → 整个界面平滑变深色，无白闪、无死黑。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 任务 Task | 一条待办定义，可重复，不等于某天的实例 |
| 发生 occursOn | 某个任务是否在某一天「需要做」 |
| 完成记录 done | `taskId + 日期` 的组合，代表某天的某个任务被勾掉 |
| 完成度 | 当天已完成任务数 / 当天应做任务数 |
| 连续天数 streak | 从今天往前数，每天「有任务且完成度 100%」的连续天数 |
| 休息日 | 当天没有任何任务。**不打断连续天数，也不计数** |
