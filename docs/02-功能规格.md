# 02 · 功能规格

> 读这一篇的目的：改任何业务逻辑前，先确认这里写的口径。
> 上层入口：`../AGENTS.md` ｜ 相关：`04-数据与状态.md`

---

## 1. 数据模型

```kotlin
enum class Repeat { NONE, DAILY, WEEKLY, MONTHLY }

data class Task(
    val id: String,            // UUID
    val title: String,         // 必填，最长 60 字
    val note: String,          // 可空，最长 300 字
    val startDate: LocalDate,  // 起始日（NONE 时即唯一发生日）
    val repeat: Repeat,
    val weekDays: Set<Int>,    // WEEKLY 用，1=周一 … 7=周日
    val monthDay: Int,         // MONTHLY 用，1..31
    val time: String?,         // "HH:mm"，null 表示不设时间
    val createdAt: Long        // 创建时间戳，用于同时间排序
)
```

完成记录独立存储，不写进 Task：`Set<String>`，元素形如 `"<taskId>|<yyyy-MM-dd>"`。
**为什么分开**：重复任务每天都要一条完成记录，写在 Task 里会让 Task 无限膨胀。

## 2. 重复规则（发生判定）

`Task.occursOn(date)` 的判定顺序，**任何一条不满足即返回 false**：

1. `date < startDate` → 不发生在该日（开始日之前一律不显示）。
2. `Repeat.NONE` → 仅当 `date == startDate`。
3. `Repeat.DAILY` → 每天都发生。
4. `Repeat.WEEKLY` → `date.dayOfWeek.value ∈ weekDays`。
   - `weekDays` 为空时视为**非法**，保存时若选了「每周」但没勾星期，自动补上 `startDate` 的星期。
5. `Repeat.MONTHLY` → `date.dayOfMonth == min(monthDay, date.lengthOfMonth())`。
   - 即：选「每月 31 日」，在 2 月会落在 28/29 日，不会消失。这是刻意的兜底。

**编辑重复规则的影响**：直接改 Task 定义即可。已产生的完成记录不会丢（按 `taskId|日期` 存），
只有该任务在那个日期原本不该发生时，记录会变成孤儿（不影响统计，因为统计按当日发生集合算）。

## 3. 每日清单

某天 `d` 的清单 = `tasks.filter { it.occursOn(d) }`，排序规则：

1. 未完成在前，已完成在后。
2. 组内按 `time` 升序；无时间的排在有时间之后。
3. `time` 相同或无时间时，按 `createdAt` 升序（先建的在上）。

分组标题：`待办 N` / `已完成 M`。全部完成时，第一天组标题右侧显示一枚 `✓ 全部完成` 标记。

## 4. 完成任务

- 点圆圈 → 切换 `done` 集合中该 `taskId|d` 的存在性，并触发一次系统触感反馈（`HapticFeedbackType.LongPress`，不申请 VIBRATE 权限）。
- 切到已完成：圆圈填充强调色 + 勾，标题加删除线并降为次要色，整行轻微下沉（150ms）。
- 取消完成：反向动画，任务回到待办组。
- 列表使用 `LazyColumn` + `key = task.id` + `Modifier.animateItem()`，跨组移动要有位移动画。

## 5. 任务编辑器

底部抽屉（`ModalBottomSheet`），字段顺序固定：

| 字段 | 规则 |
|---|---|
| 标题 | 单行，自动聚焦，占位「要做点什么？」。为空时保存按钮禁用 |
| 详情 | 多行（最多 4 行可见），占位「添加详情（可选）」。空则不显示在列表里 |
| 日期 | 快捷片：今天 / 明天 / 后天 / 选择日期…。选择日期弹出月历对话框 |
| 重复 | 四段选择：不重复 / 每天 / 每周 / 每月 |
| └ 每周 | 展开 7 个星期片，默认选中起始日的星期 |
| └ 每月 | 展开「每月 N 日」步进器（1..31，步进 1） |
| 时间 | 快捷片：不设时间 / 08:00 / 12:00 / 18:00 / 21:00 / 自定义…。自定义弹小时+分钟步进对话框 |
| 主按钮 | 位于抽屉**右上角**（不是底部），保证软键盘弹出时依然可见可点 |
| 顶部 | 左：`新任务` / `编辑任务` 标签；右：编辑态圆形删除按钮 + 主按钮「添加」/「保存」 |

保存行为：
- 新建：`startDate` 为用户所选日期，`createdAt = now`。
- 编辑：保留 `id` 与 `createdAt`，其余字段覆盖。
- 若把重复任务的日期改成未来某天，则从该天开始生效（历史记录保留）。
- 删除：二次确认（底部弹一个确认条），同时清理该 task 的所有完成记录。

## 6. 统计口径（严格按此实现）

设参考日 `T = 今天`。

| 指标 | 公式 |
|---|---|
| 当日应做 `total(d)` | `tasks.count { it.occursOn(d) }` |
| 当日已完成 `doneCount(d)` | `total(d)` 中在 done 集合里存在的条数 |
| 当日完成度 `rate(d)` | `total(d) == 0 ? 0 : doneCount / total` |
| **连续天数 streak** | 从 `T` 往前逐日；若 `T` 有任务但未全部完成，则从 `T-1` 起算。遇到「有任务且 rate < 1」当日终止；遇到 `total == 0`（休息日）**跳过不计数也不终止**；最多回溯 3650 天 |
| 30 天平均 | 最近 30 天中 `total > 0` 的日子，`rate` 的算术平均；无数据时为 0 |
| 累计完成 | done 集合中，日期 ≥ `T - 365` 的条数 |
| 近 7 天柱状 | `T-6 … T` 的 `rate`，按星期几标注 |
| 近 8 周热力 | 以 `T` 所在周为最后一周，往前共 8 周、56 天；每格颜色由该日 `rate` 决定 |

热力图配色（浅色模式）：
- `total == 0` → 线条色（空格）
- `rate == 0` → `accentSoft`
- `0 < rate < 1` → `accent` 的 25%~75% 透明度插值
- `rate == 1` → `accent` 实色

## 7. 日期条（今日页顶部）

- 横向 `LazyRow`，展示 `今天-14 … 今天+45` 共 60 天。
- 进入页面时自动滚动到选中日期并居中，无动画闪烁。
- 每格：上方星期（一…日 / 今天显示「今」），下方日号。
- 选中态：实心墨色胶囊 + 米白文字；今天态：底部一个小圆点。
- 有任务的日子：格子上方显示 1 个 3dp 小点（未完成）或多个（已完成，用强调色）。

## 8. 日历页

- 月视图，周一为每周第一天。
- 每格：日号 + 下方 1 个 4dp 状态点（有未完成任务 → 强调色；全部完成 → 次要色；无任务不显示）。
  > 刻意只用一个点而不是任务数点阵：一屏 42 格全部打点会非常吵，状态点的信息价值更高。
- 今天：1dp 描边圆环。选中：实心墨色圆。
- 非本月日期：日号降为 tertiary 色，仍可点击。
- 顶部「‹ 2026年11月 ›」切换月份，翻月时月网格淡入 + 轻微横移。
- 当前月不是今天所在月，或选中日期不是今天时，标题右侧出现「今天」小按钮；
  点击后回到今天所在月并选中今天。点击月份标题同样回到今天。
- 下方展示选中日清单，复用今日页的任务行组件。

## 9. 边界与异常

| 场景 | 行为 |
|---|---|
| 标题为空点保存 | 按钮禁用，不弹错误提示 |
| 标题超 60 字 | 输入框硬截断 |
| 详情超 300 字 | 输入框硬截断 |
| 笔记正文为空 | 「完成」按钮禁用，不产生空卡片 |
| 笔记标题超 40 字 / 正文超 5000 字 | 输入框硬截断 |
| 同一天多篇笔记 | 按创建时间倒序，新的在上 |
| 某天没有任何任务 | 显示空状态插画 + 文案 + 添加按钮 |
| 数据文件损坏 | 捕获异常，备份为 `zhuri_data.bak.json`，以空数据启动，不崩溃 |
| 跨天（App 在后台过了零点） | 回到前台时重算「今天」，日期条与完成度自动刷新 |
| 系统语言非中文 | 文案仍为中文（v1 不国际化） |
| 时区变化 | 使用设备本地时区，日期按 `LocalDate.now()` |

## 10. 笔记（v1.3）

```kotlin
data class DiaryEntry(
    val id: String,            // UUID
    val title: String = "",    // 可空，最长 40 字
    val content: String,       // 必填，最长 5000 字
    val date: LocalDate,       // 归属日期，可补记最近 7 天
    val createdAt: Long,
    val updatedAt: Long
)
```

- v1.3 起 UI 统一称「笔记」（数据字段仍是 `entries`，不迁移）。
- 独立第四个 Tab「笔记」，按日期倒序分组；同一天可写多篇，组内新的在上。
- 列表卡片：有标题时 16sp 标题 + 14sp 正文最多 3 行；无标题时正文直接作为主文案（最多 5 行）。
- 元信息只显示 `HH:mm · N 字`；编辑过的条目追加 `· 已编辑`。字数按正文去空白字符统计，标题不计入。
- 新建默认归入今天，可在编辑器选最近 7 天补记；点卡片进入编辑，编辑态可删除。
- 未来日期不显示笔记入口（笔记是回望，不是预告）；从未来日期新建也会落回今天。
- 编辑器：标题可空，正文必填；正文为空时「完成」按钮禁用。顶部关闭 / 删除 / 完成始终可见，正文区随键盘收缩并可滚动。
- 删除二次确认；删除后列表立即消失，数据落盘。
- 今日页底部增加「这一天的笔记」：没有时显示一句写作入口；有时显示最新一篇，超过一篇给「查看全部」。
- 总结页新增写作统计卡片；没有笔记时显示「去写」空状态。
- 笔记不参与任务完成率与任务连续天数，两类数据分开计算。

## 11. 笔记统计口径（v1.2）

设参考日 `T = 今天`，`D = 所有笔记的日期集合`。

| 指标 | 公式 |
|---|---|
| 总篇数 | `entries.size` |
| 写作天数 | `D.size` |
| 总字数 | 所有正文去空白后的字符数之和 |
| 本月篇数 | 归属日期的年、月都等于 `T` 的条目数 |
| 写作连续 | 若 `T ∈ D` 从 `T` 起，否则从 `T-1` 起，向前逐日检查 `D`，遇到不在 `D` 的日期终止；今天还没写不算断 |
| 最长连续 | 把 `D` 升序排列，相邻日期差 1 天则连续，取最长一段 |
| 写作热力 | 以 `T` 所在周为最后一列，向前 12 周 × 7 天；格子颜色只区分「写了 / 没写」，未来的格子不显示 |

热力配色：写了 → `accent` 实色；没写 → `line`；今天还没写 → `accent` 45% 描边；未来 → 透明。

## 12. 分类管理（v1.5）

- 默认五类：想法 / 生活 / 工作 / 学习 / 其他；用户可以自行新增、删除分类。
- 入口：写作抽屉「归到哪一类 → 管理分类」。
- 规则：名称去空格后最多 8 个字符，不可与已有分类重名；至少要保留一个分类。
- 删除某分类时，该分类下的笔记自动移到剩下的第一个分类，不丢数据。
- 总结页的分类占比与图例按实际存在的分类动态生成；自定义分类按名称稳定取色，同名永远同色。

## 13. 搜索与分类选择（v1.6）

- 笔记页顶部固定搜索框，实时过滤标题与正文（不区分大小写），与分类筛选叠加生效。
- 分类不再是横向滚动的胶囊，改为「当前分类 ▾」选择器；点开弹出底部列表，显示每个分类的篇数与选中勾。
- 分类再多也只占一列可滚动列表，不会把页面撑宽。
- 搜索结果为空时给出「没有找到 + 清除筛选」，不是空白页。

## 14. 快速回到今天（v1.7）

- 只要日期条处于滑动状态（无论是否选中某天），今日页头部立即出现「回到今天」胶囊。
- 点击后：选中日切回今天，并把日期条滚回今天；即使当前选中的就是今天，也会强制回滚。
- 停止滑动且选中日就是今天时，胶囊自动淡出，不占视觉。

## 15. 总结的补充指标（v1.7）

- 笔记：显示「共 N 个分类 · M 个已有笔记」，可切换「显示全部 / 只看已有」；没有笔记的分类以灰点 + 0 显示。
- 笔记：新增「近 7 天」逐日篇数，直接看出哪一天写了几篇；下方保留 12 周热力图。
- 日程：近 7 天柱状图标题显示「本周完成率 · 较上周 ±X%」，用来判断当前状态是在变好还是变差。
