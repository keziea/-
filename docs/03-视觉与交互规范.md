## 1. 设计基调

三个词：**暖、静、准**。

- **暖**：底色不是纯白，而是带一点米黄的纸色；卡片是纯白，靠一点点色差分层，不用重阴影。
- **静**：全屏只有**一个**强调色（赤陶番茄红），除此之外全是墨色灰阶。不用渐变堆叠、不用彩色图标。
- **准**：字号与间距用 4dp 网格；同类元素在同一屏内绝不出现两种圆角。

参考气质：纸质手账的触感 + 现代排版 App 的克制。

## 3. 字体

系统字体即可（不打包字体文件，保证 APK 小、启动快）。**数字与标题靠字重和字号拉开层级**。

| 样式 | 字号 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `display` | 56sp | Normal | -1sp | 今日的大日号 |
| `displaySerif` | 50sp | Normal | -0.5sp | 统计页的大数字（`FontFamily.Serif`） |
| `dateNum` | 25sp | Normal | -0.3sp | 笔记时间轴的日号（`FontFamily.Serif`） |
| `h1` | 28sp | Bold | -0.6sp | 页面主标题（总结 / 日历月份） |
| `h2` | 20sp | Bold | -0.3sp | 卡片标题、抽屉标题 |
| `body` | 16sp | Medium | 0 | 任务标题 |
| `bodySm` | 14sp | Normal | 0 | 任务详情 |
| `reading` | 15sp / 24sp | Normal | 0 | 笔记正文与阅读型文本 |
| `label` | 12sp | Medium | 1.2sp | 分组标签（待办 3）、字段名 |
| `caption` | 11sp | Normal | 0.2sp | 时间、重复说明、坐标轴 |

中文字重只用 `Normal / Medium / Bold` 三档，不用 Light（小字号发虚）。

## 4. 间距与圆角

**间距刻度**：4 / 8 / 12 / 16 / 20 / 24 / 32 dp。页面左右安全边距统一 **22dp**。

| 元素 | 圆角 |
|---|---|
| 任务卡 | 18dp |
| 卡片（统计） | 22dp |
| 主卡 / 抽屉顶部 | 26dp / 28dp |
| 胶囊按钮、日期格 | 全圆角 |
| 小圆点、复选框 | 圆形 |

**阴影**：几乎不用。分层靠 `paper → surface` 的明度差 + `line` 描边。唯一例外是悬浮导航与 FAB，用 `softShadow`（y=8dp, blur=24dp, 黑色 8%）。

## 5. 动效

| 场景 | 曲线 / 时长 |
|---|---|
| 勾选完成（圆圈填充 + 划线 + 行下沉） | `spring(dampingRatio = 0.75, stiffness = 520)` |
| 进度环数值变化 | `animateFloatAsState` + `tween(650, FastOutSlowInEasing)` |
| 任务增删 / 跨组移动 | `Modifier.animateItem(fadeInSpec, placementSpec, fadeOutSpec)` |
| Tab 切换 | `fadeIn(tween(190)) + fadeOut(tween(130))`，不做整页横移，减少大面积合成 |
| 悬浮按钮按压 | 缩到 0.90，`spring(dampingRatio = 0.55, stiffness = 700)` |
| 导航项按压 | 缩到 0.94，`spring(dampingRatio = 0.6, stiffness = MediumLow)` |
| 笔记增删 | `Modifier.animateItem()` |
| 笔记卡按压 | 0.985 缩放，`spring(dampingRatio = 0.7, stiffness = MediumLow)`，无水波纹 |
| 日历翻月 | `fadeIn(tween(180)) + slideInHorizontally(tween(220))`，方向由月份先后决定 |
| 日历「今天」按钮 | `fadeIn(160) + slideInHorizontally(200) { it / 3 } + expandHorizontally(200)`，退出淡出 + 收窄 |
| 抽屉弹出 | Material3 默认（已足够顺滑） |
| 柱状图 / 热力图入场 | 依次 0→目标值，每根 delay 35ms |

**性能红线**：任何列表滚动不得低于 60fps。禁止在 `item` 里做日期解析以外的重计算；统计结果用 `remember(tasks, done, today)` 缓存。

```
[24dp 圆复选框] 12dp [标题 16sp / 详情 14sp 最多 2 行 / 元信息 11sp] (weight) 8dp [时间 11sp]
```

- 元信息行：`09:30` + `·` + `每天` / `每周一三五` / `每月 12 日`。无则整行不占位。
- 已完成：标题 `lineThrough` + `ink3`，整卡透明度 0.62。

### 6.2 进度环 `ProgressRing`
- 尺寸 58dp（今日页）/ 64dp（统计主卡）；线宽 5dp；圆头端点。
- 轨道：`line`；进度：`accent`；深色主卡内轨道为 `onInk` 12% 白。
- 中心文字：`14sp` Semibold，显示 `62%`（整数四舍五入）。

### 6.3 日期条 `DateStrip`
- 每格 40×64dp，间距 5dp；外层左右各 22dp 内边距并裁剪，滚动时不溢出到页边距。
- 一屏正好容纳一周 7 天 + 前后各露出半格作为可滑动的暗示。
- 选中为 `ink` 实心胶囊，文字 `onInk`；今天未选中时 1dp `accent` 42% 描边（比 `line` 更容易一眼找到今天）。
- 上方星期 10sp，下方日号 17sp Medium，底部 4dp 状态点：有未完成 `accent`，全部完成 `ink3`。

### 6.4 悬浮导航 `FloatingNav`
- 胶囊高约 49dp，圆角全圆，`surface` 底 + `line` 描边 + `softShadow`。
- 四项等宽（今日 / 日历 / 笔记 / 总结）：图标 16dp + 间距 5dp + 文字 11sp，单行不换行。
- 选中项底色 `ink`（文字 `onInk`），未选中透明（`ink3`）；底色与字色各 180–200ms 过渡。
- 胶囊占满可用宽度，左右 22dp 不贴边，最大 560dp，居中；距屏幕底部 = 导航栏高度 + 14dp。
- 按键按下缩到 0.94，用 spring 回弹，不使用水波纹。

### 6.5 主按钮
- 抽屉内：高 36dp 胶囊，`accent` 底 + `onInk` 文字 13sp Medium，置于抽屉右上角；标题为空时降为 `surfaceAlt` 底 + `ink3` 文字且不可点。
- 悬浮添加按钮：56dp 圆形，`accent` 底 + `onInk` 加号（线宽 2.6dp），右侧距边 22dp、底部距导航 92dp，带 `softShadow`。
  > 早期做过「＋ 添加」的加长胶囊，实测会压住任务卡的详情文字（130dp 宽），改成圆形后遮挡面积降到 1/3。

### 6.7 近 7 天柱状图
- 容器高 76dp，柱宽 18dp，圆角 6dp，柱间距均分（`Row` + `weight(1f)`）。

### 6.9 空状态
- 自绘插画 76dp：一个 `accentSoft` 圆 + `accent` 描边的勾 + 两颗小星点。

### 6.10 日历「今天」按钮与翻月
- 按钮：`surfaceAlt` 胶囊，内边距 10/7dp，5dp 强调色圆点 + 11sp「今天」；放在月份标题与翻月箭头之间。
- 出现条件：查看月份 ≠ 今天所在月，或选中日期 ≠ 今天；`fadeIn(160) + slideInHorizontally(200) + expandHorizontally(200)` 进入，淡出 + 收窄退出。
- 点击：回到今天所在月并选中今天；点击月份标题同样回到今天。
- 翻月：月网格 `AnimatedContent`，淡入 180ms + 1/8 宽度横移 220ms，退出淡出 120ms；方向由月份先后决定。

## 8. 暗色模式

- 跟随系统（`isSystemInDarkTheme()`），不提供手动开关（v1 决策，减少一个设置项）。
- 深色下卡片不再靠描边分层，靠 `surface` 与 `paper` 的 6% 明度差；`line` 仅用于分隔。
- 深色主卡（统计 hero）在深色模式下改为 `surfaceAlt` 底，避免和背景糊在一起。
- 状态栏图标颜色随主题切换（`enableEdgeToEdge` + `SystemBarStyle`）。

## 9. 品牌图标与启动动画

### 9.1 图形语言

一个奶白色的太阳，正从一条地平线后面升起。对应「逐日」这个名字——每天都是新的一天。
**不用「日」字、不用日历格**：中文单字在桌面小尺寸下笔画会糊，日历格又和一堆效率类 App 撞脸。
太阳 + 地平线是两笔就能读完的图形，缩小到 48dp 依然成立。

### 9.2 自适应图标（画布 108×108，内容限制在半径 36 的真实启动器遮罩内）

| 层 | 形状 | 参数 |
|---|---|---|
| 背景 | 线性渐变矩形 | `#F4825A`（左上）→ `#CC4526`（右下），`angle=315` |
| 光晕 | 圆 | 半径 24.5，圆心 (54,47)，`#FDF6EE` 9% 透明 |
| 光芒 | 三条圆头线段 | 从太阳中心起 r18→r24，线宽 5.2，角度 -90°、-138°、-42° |
| 太阳 | 圆 | 半径 14.5，圆心 (54,47)，`#FDF6EE` |
| 地平线 | 圆角横条 | x 30→78、y 68.8→75.4，圆角 3.3 |
| 单色层 | 光芒 + 太阳 + 地平线 | 纯白实色，供 Android 13+「主题图标」自动染色 |

**为什么非要有光芒**：去掉光芒后「圆 + 横条」在圆形遮罩下会被读成「人像（头 + 肩）」，
加上三道短光芒后才锁定为「太阳」。这是被真机截图否掉一版之后加回来的。

**安全边界**：所有内容到画布中心 (54,54) 的距离 ≤ 34，遮罩半径 36，留 5% 余量。
最紧的是向上那道光芒的端点（≈33.6）。地平线两端 ≈28.2。

### 9.3 启动动画（桌面图标本身不能动，动效放在启动瞬间）

系统启动画面（Android 12+ 自动）先显示同一个图标，随后由 Compose 接管一段 620ms 动画，视觉上是连续的：

| 进度 | 动作 |
|---|---|
| 0 → 42% | 太阳从 +20dp 上浮到位（OutCubic），光芒与太阳同时淡入 |
| 8% → 46% | 地平线从中心向两端生长 |
| 28% → 50% | 「逐日」二字淡入并上移 20px，字距 4sp |
| 50% → 84% | 静止停留（约 210ms，让「图标 + 字」被看清） |
| 84% → 100% | 整层（含纸色背景）一起淡出，卡片放大到 1.05 |

卡片：100dp 圆角方块（28dp 圆角），渐变与图标背景一致，带 22dp 柔和投影。
动画期间主界面已在下面完成首帧，整层（含纸色背景）一起淡出，不会出现「先闪一下空白再进页面」。
系统启动画面（Android 12+）的图标被设为**全透明**（`ic_splash_blank`），否则平台会把图标画成 192dp 的大圆，
和这张 100dp 的圆角卡片尺寸对不上，衔接时会明显「缩一下」。

## 10. 笔记页与写作页（v1.3）

### 10.1 笔记列表
```

│ ┌───────────────────────────────────┐ │
│ │ ▍ 写给今天                    +    │ │  ← surfaceAlt 入口，2dp 强调色书签

│ └───────────────────────────────────┘ │
│ 十一月  2026 ───────────────────────── │  ← 18sp 衬线月名 + 年份 + 1dp 细线
│ 7     ┃ ┌───────────────────────────┐ │
│ 今天  ┃ │ ▍ 傍晚的风                │ │  ← 25sp 衬线日号 + 1dp 日期脊线
```

- 月份是 18sp 衬线字 + 10sp 年份 + 1dp 细线；不再使用全大写小标签。
- 日号 25sp 衬线、42dp 栏宽；今天用 `accent`，其余 `ink`；下方 9sp「今天 / 周五」。
- 日期栏底部向下延伸 1dp **日期脊线**：今天用 28% `accent`，其它日期 `line`；下一组自然断开。
- 卡片**无边框**，白底 18dp 圆角，内边距 16/15；左侧 2dp × 24dp 圆角「书签条」：今天 75% `accent`，其它 28% `ink3`。
- 标题 18sp **衬线** Medium；正文 14sp / 20sp 最多 3 行；无标题时正文升级为 `reading` 15sp / 24sp，最多 5 行。
- 卡片有 0.985 的按压缩放（spring），不使用水波纹；元信息 10sp：`HH:mm · N 字`，编辑过的追加 `· 已编辑`。
- 同一天多篇时，组内按创建时间倒序排列；日期组增删使用 `animateItem()`。
- 空状态：`accentSoft` 圆 + 自绘笔，文案「从今天的一句话开始」，下方文字按钮「写第一页」。
- 列表底部一行 10sp 灰字「笔记只留在这台设备上」。

### 10.2 今日页的笔记
- 任务区之后增加「笔记 N」分组；标题右侧「写一页」。
- 没有笔记：`surfaceAlt` 入口卡「给这一天留一句话」，同样有 2dp 书签条。
- 有笔记：显示最新一篇的紧凑卡（正文最多 2–3 行），多于一篇时下方给「还有 N 篇 / 查看全部」。
- 今日条目若属于今天，书签条使用强调色；其它日期用灰条。

### 10.3 写作抽屉
- 近全屏（高度 94%），顶部圆角 28dp；顶部栏：左关闭圆钮、标签「写笔记 / 编辑笔记」、右删除（编辑态）与「完成」胶囊。
- 标题 **22sp 衬线**，占位「给这一页起个名字（可选）」；正文 `reading` 15sp / 26sp，占位「今天，想记下什么？/ 不必完整，真实就好。」，最小高度 240dp。
- 正文下方右对齐 10sp 字数；再往下是「记在哪一天」7 个最近日期胶囊（今天 / 昨天 / 月日），横向滚动。
- 顶部栏与日期区固定，中间内容可滚动；`imePadding()` 跟随键盘，完成按钮永不被遮挡。
- 正文为空时「完成」降为 `surfaceAlt` 底 + `ink3` 字且不可点。

### 10.4 总结页写作卡片
- 白底 22dp 圆角卡：左侧「笔记」标签 + 38sp serif 总篇数；右侧「● 连续 N 天」+「最长 N 天」。
- 第二行 11sp 灰字：`在 N 天里写下 · 本月 N 篇 · 共 N 字`。
- 12 周 × 7 天写作热力：格子 11dp、间距 4dp、圆角 3dp；写了 `accent`，没写 `line`，未来透明，今天未写用 45% `accent` 描边。
- 热力下方「12 周前 / 今天」9sp；底部「最近 11月7日」+「查看全部」。
- 没有笔记时，整卡降级为一行入口：笔图标 +「还没有笔记」+「去写」。

## 11. 自适应布局（v1.2.1 起）

- **内容列**：所有页面内容最大宽 **720dp**，在平板 / 横屏 / 折叠屏上水平居中；手机上（<720dp）铺满。
  这样任务卡、日记正文、统计卡不会被拉成很长的横线。
- **导航**：最大宽 560dp，始终居中，左右至少 22dp；手机自然收窄到可用宽度，不做生硬的断点跳变。
- **FAB**：右边距 = `(屏幕宽 - 720dp) / 2 + 22dp`（窄屏为 22dp），与内容右边界对齐。
- **统计图**：近 7 天柱状图最大宽 360dp、三个数字块最大宽 520dp，居中；宽屏下不把柱子拉散。
- **对话框**：日期选择最大宽 420dp、时间选择最大宽 380dp，居中；任务 / 笔记抽屉由 Material3 默认限制在 640dp。
- **验收宽度**：320 / 360 / 600 / 1066dp（横屏）四档；高度不足时只滚动，不裁切输入入口。
- 不使用第二套平板布局：保持同一条「安排 → 完成 → 回望」主链路，只调整内容宽度与留白。

## 12. 无障碍

- 所有可点击元素最小点击区 **44dp**（复选框视觉 24dp，外套 44dp 点击热区）。
- 任务行提供 `contentDescription`：「读20页书，未完成，每天，08:00」。
- 笔记卡提供 `onClickLabel = "打开笔记"`，写作入口提供 `onClickLabel = "写笔记"`。
- 对比度：正文 `ink` 对 `paper` ≥ 12:1；`ink3` 仅用于辅助信息，不承载关键操作。

## 12. 搜索与选择器（v1.6）

- 搜索框高 40dp、圆角 20dp、`surfaceAlt` 底，左侧 14dp 搜索图标，右侧有内容时出现清除按钮。
- 分类选择器为胶囊：`surfaceAlt` 底、12sp 次要色文字 + 9dp 下箭头，点击弹出底部列表。
- 选择列表每行 44dp：分类色点 7dp + 名称 15sp + 篇数 11sp + 选中勾。
- 平板（≥600dp）：笔记列表限宽 560dp 居中，避免行宽过长；其余页面限宽 720dp。
