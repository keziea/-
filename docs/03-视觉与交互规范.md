## 1. 设计基调

三个词：**暖、静、准**。

- **暖**：底色不是纯白，而是带一点米黄的纸色；卡片是纯白，靠一点点色差分层，不用重阴影。
- **静**：全屏只有**一个**强调色（赤陶番茄红），除此之外全是墨色灰阶。不用渐变堆叠、不用彩色图标。
- **准**：字号与间距用 4dp 网格；同类元素在同一屏内绝不出现两种圆角。

参考气质：纸质手账的触感 + 现代排版 App 的克制。

## 3. 字体

系统字体即可（不打包字体文件，保证 APK 小、启动快）。**数字与标题靠字重和字号拉开层级**。

| 样式 | 字号 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `display` | 56sp | Normal | -1sp | 今日的大日号 |
| `displaySerif` | 50sp | Normal | -0.5sp | 统计页的大数字（`FontFamily.Serif`） |
| `h1` | 28sp | Bold | -0.6sp | 页面主标题（总结 / 日历月份） |
| `h2` | 20sp | Bold | -0.3sp | 卡片标题、抽屉标题 |
| `body` | 16sp | Medium | 0 | 任务标题 |
| `bodySm` | 14sp | Normal | 0 | 任务详情 |
| `label` | 12sp | Medium | 1.2sp | 分组标签（待办 3）、字段名 |
| `caption` | 11sp | Normal | 0.2sp | 时间、重复说明、坐标轴 |

中文字重只用 `Normal / Medium / Bold` 三档，不用 Light（小字号发虚）。

## 4. 间距与圆角

**间距刻度**：4 / 8 / 12 / 16 / 20 / 24 / 32 dp。页面左右安全边距统一 **22dp**。

| 元素 | 圆角 |
|---|---|
| 任务卡 | 18dp |
| 卡片（统计） | 22dp |
| 主卡 / 抽屉顶部 | 26dp / 28dp |
| 胶囊按钮、日期格 | 全圆角 |
| 小圆点、复选框 | 圆形 |

**阴影**：几乎不用。分层靠 `paper → surface` 的明度差 + `line` 描边。唯一例外是悬浮导航与 FAB，用 `softShadow`（y=8dp, blur=24dp, 黑色 8%）。

## 5. 动效

| 场景 | 曲线 / 时长 |
|---|---|
| 勾选完成（圆圈填充 + 划线 + 行下沉） | `spring(dampingRatio = 0.75, stiffness = 520)` |
| 进度环数值变化 | `animateFloatAsState` + `tween(650, FastOutSlowInEasing)` |
| 任务增删 / 跨组移动 | `Modifier.animateItem(fadeInSpec, placementSpec, fadeOutSpec)` |
| Tab 切换 | `fadeIn(tween(220)) + slideInHorizontally(初始 12dp)`，反向对称 |
| 抽屉弹出 | Material3 默认（已足够顺滑） |
| 柱状图 / 热力图入场 | 依次 0→目标值，每根 delay 35ms |

**性能红线**：任何列表滚动不得低于 60fps。禁止在 `item` 里做日期解析以外的重计算；统计结果用 `remember(tasks, done, today)` 缓存。

- 元信息行：`09:30` + `·` + `每天` / `每周一三五` / `每月 12 日`。无则整行不占位。

### 6.2 进度环 `ProgressRing`
- 尺寸 58dp（今日页）/ 64dp（统计主卡）；线宽 5dp；圆头端点。

- 每格 40×64dp，间距 5dp；外层左右各 22dp 内边距并裁剪，滚动时不溢出到页边距。

- 选中为 `ink` 实心胶囊，文字 `onInk`；今天未选中时 1dp `accent` 42% 描边（比 `line` 更容易一眼找到今天）。
- 上方星期 10sp，下方日号 17sp Medium，底部 4dp 状态点：有未完成 `accent`，全部完成 `ink3`。

### 6.4 悬浮导航 `FloatingNav`
- 胶囊 高 62dp，圆角 全圆，`surface` 底 + `line` 描边 + `softShadow`。
- 三项等宽：图标 20dp + 文字 11sp，选中项底色 `ink`（文字 `onInk`），未选中透明（`ink3`）。
- 距屏幕底部 = 导航栏高度 + 14dp；左右 22dp（不贴边）。

### 6.5 主按钮
- 抽屉内：高 36dp 胶囊，`accent` 底 + `onInk` 文字 13sp Medium，置于抽屉右上角；标题为空时降为 `accent` 32% 且不可点。
- 悬浮添加按钮：56dp 圆形，`accent` 底 + `onInk` 加号（线宽 2.6dp），右侧距边 22dp、底部距导航 92dp，带 `softShadow`。
  > 早期做过「＋ 添加」的加长胶囊，实测会压住任务卡的详情文字（130dp 宽），改成圆形后遮挡面积降到 1/3。

### 6.7 近 7 天柱状图

## 8. 暗色模式

- 跟随系统（`isSystemInDarkTheme()`），不提供手动开关（v1 决策，减少一个设置项）。
- 深色下卡片不再靠描边分层，靠 `surface` 与 `paper` 的 6% 明度差；`line` 仅用于分隔。
- 深色主卡（统计 hero）在深色模式下改为 `surfaceAlt` 底，避免和背景糊在一起。
- 状态栏图标颜色随主题切换（`enableEdgeToEdge` + `SystemBarStyle`）。

## 9. 品牌图标与启动动画

### 9.1 图形语言

一个奶白色的太阳，正从一条地平线后面升起。对应「逐日」这个名字——每天都是新的一天。
**不用「日」字、不用日历格**：中文单字在桌面小尺寸下笔画会糊，日历格又和一堆效率类 App 撞脸。
太阳 + 地平线是两笔就能读完的图形，缩小到 48dp 依然成立。

### 9.2 自适应图标（画布 108×108，内容限制在半径 36 的真实启动器遮罩内）

| 层 | 形状 | 参数 |
|---|---|---|
| 背景 | 线性渐变矩形 | `#F4825A`（左上）→ `#CC4526`（右下），`angle=315` |
| 光晕 | 圆 | 半径 24.5，圆心 (54,47)，`#FDF6EE` 9% 透明 |
| 光芒 | 三条圆头线段 | 从太阳中心起 r18→r24，线宽 5.2，角度 -90°、-138°、-42° |
| 太阳 | 圆 | 半径 14.5，圆心 (54,47)，`#FDF6EE` |
| 地平线 | 圆角横条 | x 30→78、y 68.8→75.4，圆角 3.3 |
| 单色层 | 光芒 + 太阳 + 地平线 | 纯白实色，供 Android 13+「主题图标」自动染色 |

**为什么非要有光芒**：去掉光芒后「圆 + 横条」在圆形遮罩下会被读成「人像（头 + 肩）」，
加上三道短光芒后才锁定为「太阳」。这是被真机截图否掉一版之后加回来的。

**安全边界**：所有内容到画布中心 (54,54) 的距离 ≤ 34，遮罩半径 36，留 5% 余量。
最紧的是向上那道光芒的端点（≈33.6）。地平线两端 ≈28.2。

### 9.3 启动动画（桌面图标本身不能动，动效放在启动瞬间）

系统启动画面（Android 12+ 自动）先显示同一个图标，随后由 Compose 接管一段 620ms 动画，视觉上是连续的：

| 进度 | 动作 |
|---|---|
| 0 → 42% | 太阳从 +20dp 上浮到位（OutCubic），光芒与太阳同时淡入 |
| 8% → 46% | 地平线从中心向两端生长 |
| 28% → 50% | 「逐日」二字淡入并上移 20px，字距 4sp |
| 50% → 84% | 静止停留（约 210ms，让「图标 + 字」被看清） |
| 84% → 100% | 整层（含纸色背景）一起淡出，卡片放大到 1.05 |

卡片：100dp 圆角方块（28dp 圆角），渐变与图标背景一致，带 22dp 柔和投影。
动画期间主界面已在下面完成首帧，整层（含纸色背景）一起淡出，不会出现「先闪一下空白再进页面」。
系统启动画面（Android 12+）的图标被设为**全透明**（`ic_splash_blank`），否则平台会把图标画成 192dp 的大圆，
和这张 100dp 的圆角卡片尺寸对不上，衔接时会明显「缩一下」。

## 10. 无障碍

- 所有可点击元素最小点击区 **44dp**（复选框视觉 24dp，外套 44dp 点击热区）。
- 任务行提供 `contentDescription`：「读20页书，未完成，每天，08:00」。
- 对比度：正文 `ink` 对 `paper` ≥ 12:1；`ink3` 仅用于辅助信息，不承载关键操作。
