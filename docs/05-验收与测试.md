## 1. 功能验收清单

### 今日页
- [ ] 首次启动无数据时显示空状态插画 + 文案 + 「添加第一件事」
- [ ] 顶部显示「2026 · 十一月 / 6 日 周四 · 今天」，日号为衬线大字
- [ ] 右上进度环：无任务时 0%，有任务时按完成比例显示
- [ ] 日期条可左右滑动，进入时自动定位到今天
- [ ] 点其它日期，清单与进度环同步切换；标题从「今天」变成「周四」
- [ ] 有任务的日期格底部有小圆点
- [ ] 点圆圈勾选：圆圈填充、标题划线、整行移到「已完成」组，有位移 + 淡入动画
- [ ] 再次点击可取消完成，行回到「待办」组
- [ ] 详情不为空时，卡片内显示详情（最多 2 行，超出省略）
- [ ] 时间为空时不显示时间标签；重复为「不重复」时不显示重复标签

### 编辑器
- [ ] 点「添加」弹出底部抽屉，标题输入框自动聚焦、键盘弹出、抽屉不被遮挡
- [ ] 标题为空时主按钮置灰不可点
- [ ] 输入标题后按钮变强调色可点
- [ ] 选「选择日期…」弹出月历，可翻月，确认后回填
- [ ] 重复切「每周」出现 7 个星期片，默认选中起始日的星期
- [ ] 重复切「每月」出现「每月 N 日」步进器，可 1~31 调整
- [ ] 时间选「自定义…」弹出小时/分钟步进器，确认后回填为 `HH:mm`
- [ ] 保存后抽屉关闭，清单立即出现新任务，无需下拉刷新
- [ ] 点已有任务打开抽屉，字段全部回填；改名保存后列表同步
- [ ] 编辑态点「删除」→ 二次确认 → 任务消失
- [ ] 保存后杀进程重启，数据仍在

### 日历页
- [ ] 周一为每周第一列，日期 1 号对齐正确
- [ ] 有任务的日期下方显示圆点（最多 3 个）
- [ ] 今天有描边圆环，选中日期为实心墨色
- [ ] `‹` `›` 正确翻月，跨年（12月→1月）正确
- [ ] 点月份标题回到今天所在月
- [ ] 点某一天，下方清单切换；下方可直接勾选完成

### 总结页
- [ ] 连续天数与手算一致（含「休息日跳过」规则）
- [ ] 今日完成度与今日页进度环一致
- [ ] 30 天平均：无数据的日子不参与平均
- [ ] 近 7 天柱状：7 根柱子，标签为星期，今天在最右
- [ ] 近 8 周热力图：56 格，今天在最后一列且位置对应星期
- [ ] 切换日期后数据不需要刷新（统计始终以「今天」为基准）

## 2. 视觉验收

- [ ] 全屏只有一种强调色（赤陶红），没有第二种彩色
- [ ] 卡片圆角统一 18/22/26，页面内无混用
- [ ] 左右边距统一 22dp，标题与卡片左边缘对齐
- [ ] 悬浮导航不贴边、不遮挡最后一条任务（列表底部留白 ≥ 110dp）
- [ ] 暗色模式下无白底白字、无死黑块，主卡与背景可区分
- [ ] 系统字体放大到 1.3x 时，任务行不重叠、不截断关键信息

## 3. 性能验收

| 指标 | 目标 | 实测方法 |
|---|---|---|
| 冷启动到首帧 | < 700ms | `adb shell am start -W` 看 `TotalTime` |
| 滚动帧率 | 60fps 无掉帧 | Android Studio Profiler / `dumpsys gfxinfo` |
| 勾选响应 | < 16ms 出视觉反馈 | 手感 + 慢动作录屏 |
| 200 条任务下列表滚动 | 不卡顿 | 造 200 条数据压测 |
| APK 体积 | < 6MB | 看产物文件大小 |
| 内存占用 | < 90MB | `adb shell dumpsys meminfo` |

## 4. 兼容性

| 项 | 覆盖 |
|---|---|
| 最低系统 | Android 8.0（API 26） |
| 目标系统 | Android 16（API 36） |
| 屏幕 | 320dp ~ 600dp 宽（小屏到大屏）均可正常布局 |
| 折叠屏 / 平板 | 单列布局，内容居中，不拉伸变形 |
| 刘海屏 / 挖孔屏 | 使用 `enableEdgeToEdge` + `WindowInsets` 避让 |

## 5. 已知限制（v1 明确不做）

1. 没有提醒推送，时间是纯展示标签。
2. 没有云同步，换机需自行导出文件（未提供导出入口）。
3. 重复规则不支持「每两周」「工作日」等复合规则。
4. 统计只回溯 365 天，更早的记录不参与「累计完成」。
5. 不国际化，仅中文。
6. 深色模式只跟随系统，无手动开关。
