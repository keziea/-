## 2026-11-07 · v1.1 · 品牌图标重做 + 启动动画

**新增**
- 全新自适应图标：暖橙渐变底（`#F4825A → #CC4526`）+ 奶白太阳（三道光芒）+ 地平线。
- Android 13+ 主题图标单色层，系统会按壁纸自动染色。
- 启动动画：560ms 日升动效（太阳上浮、地平线由中心向两端生长、字标淡入），主界面先完成首帧再整层淡出。
- 勾选任务时的触感反馈。

**修复**
- 首版图标「圆 + 横条」在圆形遮罩下会被读成「人像（头 + 肩）」。加三道光芒后才锁定为太阳。
  对比过程见 `scripts/icon_preview.py`：纯 Python 光栅化，按真实遮罩半径（36/108）渲染，不依赖 Pillow。
- 启动动画结束时只有卡片淡出、纸色背景还在，会闪一下空白 → 改为整层一起淡出。
- 系统启动画面会把自适应图标画成 192dp 的大圆，和 100dp 的圆角卡片尺寸对不上、衔接时「缩一下」
  → 系统启动图标设为全透明（`ic_splash_blank`），启动瞬间交给 Compose 独占。
- 日期条里「今天」未选中时的描边太淡（`line`）→ 改为 `accent` 42%。

**工程**
- 版本号 1.0 → 1.1（versionCode 2）。

## 2026-11-06 · v1.0 · 模拟器验收后的打磨（发布前，并入首个版本）

**修复**
- 日期条一屏放不下 7 天（370dp > 316dp 可用宽度）→ 单元格 46→40dp、间距 8→5dp，并改为在外层裁剪，滚动时不再有内容溢出到页边距。
- 任务卡详情文字被 130dp 宽的加长 FAB 压住 → 改为 56dp 圆形 FAB。
- 编辑器主按钮在软键盘弹出时被顶出屏幕 → 主按钮移到抽屉右上角（标题/详情下方仍可滚动）。
- 自定义时间（如 10:00）的选中态落在横向滚动区外，看起来像没设时间 → 自定义时间片提到「不设」之后，选中态永远可见。
- 空状态页面同时出现「还没有安排」和「今天还空着」两句冗余文案 → 无任务时不再显示头部统计行。
- 切换深色模式后状态栏/导航栏图标仍是深色（Manifest 声明了 `configChanges=uiMode`，Activity 不重建，`enableEdgeToEdge()` 不会重跑）→ 在 Compose 里监听 `isSystemInDarkTheme()` 手动更新 `isAppearanceLightStatusBars`。

**调整**
- 日历每格从「最多 3 个任务数点」改为「1 个状态点」（未完成=强调色 / 全完成=次要色），42 格全部打点过于嘈杂。
- 热力图格子 15→20dp，填满卡片宽度，不再显得空。

**新增**
- 新建任务自动聚焦标题并唤起键盘（编辑已有任务不抢焦点）。
- `scripts/seed_demo.py`：生成演示数据（5 个任务 + 88 条完成记录），用于截图与统计校验。

**工程**
- 构建环境补齐：JDK 17 + Gradle 8.13 装到 `E:\AndroidDev`；Android SDK 系统镜像从腾讯云镜像获取（官方源 250KB/s）。
- 记录 7 条本机踩坑与解法，见 `01-目录结构与构建.md` 第 8 节。

## 2026-11-06 · v1.0.0 · 首个可用版本

**新增**
- 完整 Android 工程：Kotlin 2.2.20 + Compose（BOM 2025.09.01）+ AGP 8.12.3 + Gradle 8.13，minSdk 26 / targetSdk 36。
- 今日页：日期头（大日号 + 完成度环）、60 天横向日期条、待办/已完成分组清单、空状态插画。
- 任务编辑器（底部抽屉）：标题、详情、日期（快捷片 + 自绘月历）、重复（不重复/每天/每周几/每月某日）、可选时间（快捷片 + 步进器）。
- 日历页：月视图、任务打点、今天描边、选中实心、下方清单可勾选。
- 总结页：连续天数主卡、今日/平均/累计三数字、近 7 天柱状图、近 8 周热力图。
- 悬浮胶囊导航 + 悬浮添加按钮，Tab 切换带淡入位移。
- 本地 JSON 原子持久化，零权限、零网络。
- 浅色 / 深色双主题，全部令牌化。

**设计**
- 暖纸底色 `#F7F4EF` + 单一赤陶强调色 `#DF5738` + 墨色灰阶；零重阴影，靠描边与色差分层次。
- 大日号与统计数字使用衬线字体（`FontFamily.Serif`），正文使用系统无衬线，靠字重拉开层级。
