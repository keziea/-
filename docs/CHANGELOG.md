## 2026-11-11 · v3.0 · 完成庆祝 + 奖杯系统 + 日历摘要

## 2026-11-08 · v1.9 · 回到今天改由「日期条位置」驱动

- 进入今日页默认在原位，不显示胶囊。
- 日期条一旦偏离原位（哪怕 1px），立刻显示「回到今天」；滑停后依然显示。
- 手动把日期条拨回原位时，胶囊自动消失。

## 2026-11-08 · v1.8 · 回到今天改为「锁定显示」

- 日期条只要滑动过一次，「回到今天」胶囊就**一直显示**，不会因为松手/滑动结束而消失。

## 2026-11-07 · v1.2 · 每日小记 + 写作总结 + 丝滑度打磨

**新增**
- 第四个 Tab「小记」：按日倒序时间轴，同一天可写多篇；月分隔线、日号衬线字、左侧日期栏。
- 沉浸式写作抽屉：标题可空、正文必填、最近 7 天补记、实时字数、编辑态删除、关闭 / 完成常驻。
- 今日页底部「这一天的小记」：空态写作入口、最新一篇预览、「还有 N 篇 / 查看全部」。
- 总结页写作卡片：总篇数、写作天数、本月篇数、总字数、当前 / 最长连续、12 周写作热力。
- 小记数据写入同一份 JSON（`entries` 数组），无新权限、无数据库。
- 自绘笔图标、四栏导航、导航 / FAB 按压缩放。

**性能 / 手感**
- 日期条 60 天、月历 42 天的状态点改为一次预计算，滚动 / 切换时不再逐格过滤任务。
- 总结页统计增加单日缓存，并以最早任务开始日截断连续天数回溯；切 Tab 不再重复全量计算。
- 小记分组与写作统计用 `remember(entries, today)` 缓存，Root 只算一次给两个页面。
- Tab 切换改为 190ms / 130ms 淡入淡出，去掉整页横移；`@Immutable` 标注数据模型，减少无谓重组。
- 导航胶囊改为四等分满宽（最大 440dp），320dp 窄屏与 1.3x 字体下不溢出。

**修复**
- 部分实现遗留的 `buildNoteStats / DiaryStatsCard` 未定义导致编译失败。
- 小记卡片无标题时不再显示「无题」占位，正文直接作为主文案。
- 写作页正文为空时「完成」置灰；标题 / 正文输入硬截断（40 / 5000 字）。

**工程**
- 版本号 1.1 → 1.2（versionCode 3）。

## 2026-11-06 · v1.0.0 · 首个可用版本

**新增**
- 完整 Android 工程：Kotlin 2.2.20 + Compose（BOM 2025.09.01）+ AGP 8.12.3 + Gradle 8.13，minSdk 26 / targetSdk 36。
- 今日页：日期头（大日号 + 完成度环）、60 天横向日期条、待办/已完成分组清单、空状态插画。
- 任务编辑器（底部抽屉）：标题、详情、日期（快捷片 + 自绘月历）、重复（不重复/每天/每周几/每月某日）、可选时间（快捷片 + 步进器）。
- 日历页：月视图、任务打点、今天描边、选中实心、下方清单可勾选。
- 总结页：连续天数主卡、今日/平均/累计三数字、近 7 天柱状图、近 8 周热力图。
- 悬浮胶囊导航 + 悬浮添加按钮，Tab 切换带淡入位移。
- 本地 JSON 原子持久化，零权限、零网络。
- 浅色 / 深色双主题，全部令牌化。

**设计**
- 暖纸底色 `#F7F4EF` + 单一赤陶强调色 `#DF5738` + 墨色灰阶；零重阴影，靠描边与色差分层次。
- 大日号与统计数字使用衬线字体（`FontFamily.Serif`），正文使用系统无衬线，靠字重拉开层级。
