# v1.2.1 · 手机 / 平板自适应

**发布日期**：2026-11-07　　**版本类型**：体验改进

手机/平板自适应布局，内容限宽居中。

## 具体内容

**调整**
- 所有页面内容宽度上限 **720dp** 并水平居中：手机上铺满，平板 / 横屏 / 折叠屏不再把卡片拉成一条长线。
- 导航胶囊最大 560dp，随可用宽度自然收窄（不断点跳变）；FAB 与内容右边界对齐。
- 总结页近 7 天柱状图最宽 360dp、三个数字块最宽 520dp，宽屏下保持紧凑比例。
- 日期 / 时间选择对话框限宽 420 / 380dp，居中显示；任务 / 笔记抽屉继续由 Material3 限制在 640dp。
- 320dp 手机、360dp 手机、600dp 平板、1066dp 横屏均实际验收。

**工程**
- 版本号 1.2 → 1.2.1（versionCode 4）。
