# v1.2 · 每日小记 + 写作总结 + 丝滑度打磨

**发布日期**：2026-11-07　　**版本类型**：功能新增

每日小记、写作统计与总结。

## 具体内容

**新增**
- 第四个 Tab「小记」：按日倒序时间轴，同一天可写多篇；月分隔线、日号衬线字、左侧日期栏。
- 沉浸式写作抽屉：标题可空、正文必填、最近 7 天补记、实时字数、编辑态删除、关闭 / 完成常驻。
- 今日页底部「这一天的小记」：空态写作入口、最新一篇预览、「还有 N 篇 / 查看全部」。
- 总结页写作卡片：总篇数、写作天数、本月篇数、总字数、当前 / 最长连续、12 周写作热力。
- 小记数据写入同一份 JSON（`entries` 数组），无新权限、无数据库。
- 自绘笔图标、四栏导航、导航 / FAB 按压缩放。

**性能 / 手感**
- 日期条 60 天、月历 42 天的状态点改为一次预计算，滚动 / 切换时不再逐格过滤任务。
- 总结页统计增加单日缓存，并以最早任务开始日截断连续天数回溯；切 Tab 不再重复全量计算。
- 小记分组与写作统计用 `remember(entries, today)` 缓存，Root 只算一次给两个页面。
- Tab 切换改为 190ms / 130ms 淡入淡出，去掉整页横移；`@Immutable` 标注数据模型，减少无谓重组。
- 导航胶囊改为四等分满宽（最大 440dp），320dp 窄屏与 1.3x 字体下不溢出。

**修复**
- 部分实现遗留的 `buildNoteStats / DiaryStatsCard` 未定义导致编译失败。
- 小记卡片无标题时不再显示「无题」占位，正文直接作为主文案。
- 写作页正文为空时「完成」置灰；标题 / 正文输入硬截断（40 / 5000 字）。

**工程**
- 版本号 1.1 → 1.2（versionCode 3）。
