# v1.3 · 笔记改名 + 日历回今天 + MuMu 兼容

**发布日期**：2026-11-07　　**版本类型**：问题修复

笔记改名、日历回到今天、兼容 MuMu 6。

## 具体内容

**兼容**
- minSdk 26 → **23（Android 6.0）**，开启 core library desugaring，用 `desugar_jdk_libs` 提供 `java.time`。
- APK 同时保留 **v1（JAR）+ v2** 签名，Android 6/7 的 MuMu 也能验证安装；无 native 库，x86 模拟器可直接跑。
- APK 1.5MB（脱糖库增加约 270KB）。

**改名 / 视觉**
- 「小记」统一更名为 **「笔记」**：导航、今日页、总结页、写作抽屉文案全部同步；数据字段仍为 `entries`。
- 笔记页重做：18sp 衬线月名、25sp 衬线日号、1dp 日期脊线、无边框纸卡、2dp 书签条。
- 笔记标题改为衬线字；空态文案改为「写给今天的一页，不必很长」；底部「笔记只留在这台设备上」。
- 写作抽屉标题 22sp 衬线，占位改为「给这一页起个名字（可选）」/「今天，想记下什么？」。
- 笔记卡片增加 0.985 按压缩放（spring），去掉水波纹。

**日历**
- 翻到其它月份 / 选中其它日期时，标题右侧出现「今天」小按钮；点击回到今天所在月并选中今天。
- 月份切换增加淡入 + 轻微横移动画；「今天」按钮淡入滑入。
- 点击月份标题同样回到今天。

**工程**
- 版本号 1.2.1 → 1.3（versionCode 5）。
