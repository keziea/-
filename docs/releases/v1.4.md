# v1.4 · 笔记分类 + 与日程视觉分离 + 流畅度

**发布日期**：2026-11-07　　**版本类型**：功能新增

笔记支持分类，与日程视觉分离，优化滚动流畅度。

## 具体内容

**命名**
- 统一称 **「笔记」**：导航、今日页、总结页、写作抽屉、文档全部同步；数据字段仍是 `entries`，不迁移。

**分类**
- 五类固定标签：想法 / 生活 / 工作 / 学习 / 其他；旧数据没有分类时回落到「想法」。
- 笔记页顶部可按分类筛选并显示篇数；写作抽屉内可选分类。
- 总结页新增分类占比条与各类篇数。

**一眼分辨**
- 笔记改用专属冷灰绿 `note`（浅色 #4E6B60 / 深色 #8FB6A8）：时间脊线、书签条、写作热力图、统计卡统一使用。
- 日程保持赤陶 `accent` + 圆形勾选；笔记是衬线标题 + 分类圆点，两套视觉语言不混。

**流畅度**
- 日期条 60 天、日历 49 格的状态一次算好缓存，切换日期不再逐格重扫任务。
- 页面切换改为 190ms 淡入淡出，去掉整页横向位移造成的大面积重绘。
- 待办/已完成列表结果缓存，勾选时只重排变化项。

**环境**
- 模拟器调整为 1080×2400 / 420dpi，截图与真机观感一致。
