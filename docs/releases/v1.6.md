# v1.6 · 分类选择器 + 笔记搜索 + 全尺寸适配

**发布日期**：2026-11-07　　**版本类型**：功能新增

分类改为选择器，新增标题/正文搜索，适配手机与平板。

## 具体内容

**分类**
- 取消横向滚动的分类胶囊，改为「当前分类 ▾」选择器：点开是完整列表，带篇数与勾选，分类再多也不用往右翻。
- 写作抽屉里的分类也改为同一个选择器，并保留「管理分类」。

**搜索**
- 笔记页新增搜索框，实时过滤标题与正文，不区分大小写；可与分类筛选叠加。
- 无结果时显示「没有找到 + 清除筛选」。

**适配**
- 笔记列表在平板 / 横屏限宽 560dp 居中，避免一行文字过长；其他页面保持 720dp。
- 总结页分类图例改为三列换行，分类数量增加也不会溢出。
- 窄屏 360dp 与平板 800dp 均实机截图验证过。
