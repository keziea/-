# v1.7 · 滑动即回到今天 + 总结补全

**发布日期**：2026-11-07　　**版本类型**：功能新增

滑动日期条即出现回到今天；总结补充分类总数、每日篇数、本周完成率。

## 具体内容

**今日**
- 日期条只要开始滑动（不必点选），头部立刻出现「回到今天」胶囊；点击切回今天并强制滚回。
- 选中日已是今天时，胶囊在滑动结束后自动淡出。

**总结**
- 笔记统计显示分类总数与已有笔记的分类数，可切换「显示全部 / 只看已有」。
- 新增近 7 天逐日笔记篇数，回答「哪一天写了几篇」。
- 日程近 7 天标题增加「本周完成率 · 较上周 ±X%」，用来判断近期是在进步还是退步。
