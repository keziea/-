# v1.9 · 回到今天改由「日期条位置」驱动

**发布日期**：2026-11-08　　**版本类型**：问题修复

回到今天改为按日期条位置判断：滑偏显示、拨回消失。

## 具体内容

进入今日页默认在原位，不显示胶囊。
- 日期条一旦偏离原位（哪怕 1px），立刻显示「回到今天」；滑停后依然显示。
- 手动把日期条拨回原位时，胶囊自动消失。
- 点击胶囊：动画滚回原位并选中今天，到达原位后胶囊消失。
- 不再根据「是否正在滑动」或「选中日期」判断，避免程序滚动误触发。
