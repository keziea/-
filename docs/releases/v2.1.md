# v2.1 · 添加入口下沉到分区

**发布日期**：2026-11-08　　**版本类型**：体验改进

添加入口下沉到日程/笔记各自标题，去掉容易误解的全局加号。

## 具体内容

今日页移除全局悬浮加号，避免「加日程还是加笔记」的歧义。
- 「日程」标题右侧新增「添加」；「笔记」标题右侧保留「写一条」，各管各的。
- 空状态仍保留「添加第一件事」，不会出现没有入口的情况。
- 日历页保留悬浮加号（那里只有日程，无歧义）。
