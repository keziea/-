# v3.0.1 · 修复奖杯墙滚动卡顿

**发布日期**：2026-11-11　　**版本类型**：问题修复

奖杯墙与总结页不再每帧重绘，勾选任务更跟手。

## 修复

- 奖杯墙里 10 座奖杯原先每座都常驻一条无限缩放动画，即使未解锁也在 60fps 重绘，导致总结页滚动发涩、耗电增加。现在只有解锁弹层里的那一座会动，静止奖杯不再产生每帧重绘。
- 「连续完成天数」原先在勾选任务时同步计算，数据多时会占用主线程。现在移到后台计算，勾选后的反馈更跟手。
- 「全部完成」庆祝层原先全屏拦截触摸 4 秒，点完最后一件事后无法继续操作。现在不铺遮罩、不拦截触摸，点卡片才关闭，3 秒自动淡出。

## 升级说明

- 直接覆盖安装，数据保留；版本号 3.0.1，versionCode 15。
