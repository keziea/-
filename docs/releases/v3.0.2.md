# v3.0.2 · 整体交互提速

**发布日期**：2026-11-11　　**版本类型**：体验改进

反馈动画更短、页面切换更快、计算更少，滑动与点击更跟手。

## 改进

- 今日页右上角的完成进度环，从 650ms 缩短到 320ms；勾选后数字与圆环立刻跟上，不再“慢慢追”。
- 任务卡的底色、边框、标题变色从 220ms 缩短到 140ms；勾选圆从 180ms 缩短到 140ms。
- 待办 / 已完成之间重排的动画从默认弹簧改为 180ms，勾完不会“飘”太久。
- 四栏导航的按压回弹更快；切页不再做整页淡入淡出，点哪个立即到哪个，不再同时合成两张页面。
- 导航悬浮条的阴影从 20dp 降到 12dp，减少一层绘制开销。
- 连续天数只在「某一天从不完整变成全部完成」或反过来时重算；普通勾选不再触发后台计算。

## 说明

- 上一版 v3.0.1 已修掉奖杯墙每帧重绘与庆祝层挡操作；这一版继续调整整体节奏。
- 覆盖安装，数据保留。
