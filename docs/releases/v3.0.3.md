# v3.0.3 · 日程滑动更顺 + 关于本机

**发布日期**：2026-11-11　　**版本类型**：体验改进

日期条吸附更稳，总结页可查看当前版本与数据概况。

## 改进

- 日期条去掉每个日期各自的两条颜色动画，横向滑动时不再反复创建动画状态。
- 日期条加入按天吸附：松手后自动对齐到最近的一天，不会停在两格之间，滑动更可控。
- 「回到今天」胶囊改为固定高度槽位，只做淡入淡出，出现时不再改变头部高度、不触发重排。
- 日期格增加稳定 key 与内容类型，横向复用更稳定。

## 新增

- 总结页底部新增「关于逐日」：显示当前版本号与 versionCode、日程总数、笔记总数、奖杯进度。
- 总结页标题下直接显示当前版本，例如 `v3.0.3 (17) · 纯本地运行`。
- 明确标注：数据只保存在本机，覆盖安装会保留，卸载会清空。

## 升级说明

- 覆盖安装，日程、笔记、分类、奖杯全部保留；不要卸载。
