# v3.0.4 · 未完成复盘与补记

**发布日期**：2026-11-11　　**版本类型**：功能新增

过去没做的事自动算未完成，可在总结页一键补记为成功。

## 新增

- 总结页新增「近 7 天未完成」：列出最近 7 天漏掉的任务与对应日期，最多显示 6 件，其余提示去日历补。
- 每条未完成右侧有「补记」：点一下就把那天标记为成功，并立即刷新连续天数与奖杯进度。
- 日历选中过去某天时，日程标题显示「成功 x · 未完成 y」；展开后每条任务标注「成功」或「未完成 · 点左侧圆圈补记为成功」。
- 补记成功后，该条立即从「未完成」列表消失。

## 设计说明

- 不额外保存「失败」字段。结果由「日期是否过去」+「当天有没有勾选」实时推导：
  - 过去 + 已勾选 = 成功
  - 过去 + 未勾选 = 未完成（失败）
  - 今天 / 未来 = 待完成
- 因此不需要后台定时任务，不会出现「忘记打开 App 就没记上失败」；补记成功也不需要改历史数据，只是补上完成记录。
- 没有新增权限、没有网络请求，旧数据无需迁移。

## 升级说明

- 覆盖安装即可，日程、笔记、分类、奖杯全部保留。
