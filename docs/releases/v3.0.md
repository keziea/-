# v3.0 · 完成庆祝 + 奖杯系统 + 日历摘要

**发布日期**：2026-11-11　　**版本类型**：功能新增

完成全天任务庆祝、十座连续奖杯、日历当天摘要；今日页只保留日程。

## 具体内容

**今日**
- 只保留日程，移除当天笔记区；笔记统一到「笔记」页。
- 当天全部日程完成时弹出轻庆祝（纸屑 + 勾选卡），每次完成都会触发。

**奖杯**
- 十座奖杯按连续完成天数解锁：1 / 7 / 14 / 30 / 60 / 100 / 180 / 365 / 500 / 1000 天。
- 自绘奖杯，五种材质；解锁时弹出奖杯庆祝动画，总结页新增奖杯墙与「下一座还差几天」。
- 升级首启按已有连续天数静默补齐，避免一次性弹十个窗。

**日历**
- 选中日改为两张摘要卡：日程「完成 x / y」可展开；笔记「n 篇 + 分类摘要」可展开，点条目直接编辑。

**安装**
- 固定签名 + 递增 versionCode，新版可直接覆盖安装并保留数据；只有卸载才会清空。
