# v3.1.0 · 大字号修复 + 数据备份

**发布日期**：2026-11-14　　**版本类型**：功能新增

回到今天不再被裁切，关于页可导出/恢复完整备份。

## 修复

- 今日页「回到今天」不再用固定 22dp 高度，槽位随系统字体缩放；文字强制单行，按钮高度同步放大，大字号下四个字完整可见，点击区域也更好按。
- 日历右上角原来的「今天」改为「回到今天」，带箭头与底色，不再让人误以为它只是一个日期标签。
- 两处按钮都扩大了触摸区域，减少误触旁边内容。

## 新增

- 关于逐日新增「导出备份」：通过系统文件选择器保存 `zhuri-backup-日期.json`，不需要存储权限。
- 新增「恢复备份」：选择备份文件后先弹确认，明确告知会覆盖当前全部数据；确认后恢复日程、笔记、分类、奖杯。
- 备份文件带 `app: zhuri` 标记，选错文件会被拒绝，不会清空数据。

## 升级说明

- 覆盖安装，数据保留。
- 建议在换机或卸载前先导出一次备份；卸载仍会清空本机数据。
