# v3.1.2 · 备份按钮独立 + 列表减负

**发布日期**：2026-11-14　　**版本类型**：体验改进

导出/恢复改为两个大按钮，任务列表去掉逐行颜色动画。

## 改进

- 「数据与备份」从关于卡片里独立出来，导出、恢复改为两个 46dp 高的大按钮：
  - 导出备份：赤陶色实心按钮；
  - 恢复备份：浅底描边按钮；
  - 两者并排，触摸区域完整，底部注明备份内容与覆盖风险。
- 任务行不再为每一行维护背景、边框、标题三条颜色动画，直接使用目标颜色；滚动和勾选少一层负担。勾选圆圈、进度环、完成庆祝仍保留动效。
- 关于卡片只保留版本、数据统计与隐私说明，不再混入操作按钮。

## 说明

- 覆盖安装，数据保留。
- 备份功能本身不变：系统文件选择器、无需存储权限、恢复前二次确认。
