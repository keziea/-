# v3.2.0 · 总结分页重构

**发布日期**：2026-11-14　　**版本类型**：体验改进

总结只留概览，奖杯/写作/备份/关于收进更多入口。

## 改进

- 总结页首页只保留每天真正会看的内容：连续天数、今日完成、30 天平均、近 7 天柱状、近 8 周热力、近 7 天未完成。
- 奖杯墙、写作统计、数据与备份、关于逐日收进底部「更多」分组，每行显示关键摘要（如「已解锁 3 / 10」）。
- 点任意一行进入独立详情页，左上角「‹ 总结」返回；系统返回键同样可返回。
- 仍保持四个底部 Tab，不新增第五个入口，避免把常用操作拆散。

## 说明

- 详情页只改变组织方式，数据与功能不变。
- 覆盖安装，数据保留。
